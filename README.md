Neon Vice Cover Studio — turn your photos into GTA 6-style multi-panel poster cover art, offline in your browser. Upload photos, pick a multi-panel layout, style the caption, grade it Vice Sunset or Neon Nights, export PNG in 1080x1080, 1080x1350 or 1920x1080.

## Run it

```sh
python3 -m http.server 8080 --directory app
```
then open http://localhost:8080
